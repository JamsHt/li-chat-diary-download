李的聊天日记 · Windows 桌面应用
构建日期：2026-10-14

安装文件：李的聊天日记.exe
平台：Windows x64（Windows 10 及以上）
软件免费使用；模型 API 和可选联网检索费用由用户自行承担。

1. 关闭正在运行的旧版程序，再运行安装包，选择安装位置。升级沿用原数据目录。
2. 首次启动会打开“模型与本地数据”。填写完整文字模型接口地址、模型名称和自己的 API Key。
3. “测试文字模型”会发送固定测试消息，可能产生模型费用。配置需点击“保存配置”后生效。
4. 截图识别与联网检索分别填写视觉模型和 Tavily 配置。不配置时，可使用不依赖对应服务的功能。
5. 可从页面右上角“本地设置”或 Ctrl+, 重新进入设置。在“怎么称呼你”填写名字并保存，右上角会显示名字，点击仍可进入设置。
6. API Key 默认遮挡，点击眼睛按钮显示／隐藏。保存、关闭设置或重启后仍保留；只有主动清空输入框或勾选清除并保存才会删除。
7. F11 切换全屏，Esc 退出全屏。已移除顶部原生菜单栏并隐藏滚动条，鼠标滚轮、触控板及键盘仍可滚动页面。
8. 本版使用棕红色双圆环 li 图标。主界面采用与参考浏览器画面一致的 16:9 内容区，恢复网页原有字号和布局。窗口或屏幕比例不同时，外侧会有深色留边；全屏不会再把首页背景和助手面板拉高。设置窗口仍可使用完整高度。
9. 右下角小信封用于查看欢迎信。名字及文字模型配置保存齐全后，会收到一封原版欢迎信；打开后未读提示消失，信件仍可随时查看。改名和重启不会重复发送。欢迎信完全在本地生成保存，不调用模型、不产生 API 费用，不连接后台客服。

数据保存在 %APPDATA%\LiChatDiary，与程序安装目录分开。
日记在本地保存，但 AI 请求所需的聊天、截图、记忆会发给用户配置的模型服务商；联网检索会发送检索词。
API 配置使用 Windows 账户加密保存。日记正文和导出的档案没有额外加密。
“导出已保存档案”不含浏览器中的助手对话、草稿和背景。完整备份请退出应用后复制整个数据目录。当前没有一键恢复功能。
卸载默认保留数据；升级使用同一个数据目录。

本版本以闭源方式分发。免费使用不意味着开放源代码。第三方组件许可证包含在应用中。
当前是未签名预览版，Windows 可能提示未知发布者。请核对下载来源以及 SHA256SUMS.txt。
尚未验证干净 Windows 环境下的安装、卸载、升级全流程，也没有使用真实收费 API 进行测试。
