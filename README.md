## 使用

- 整理真实聊天，练习虚拟对话，保存和查找档案。
- 日记助手可以帮助回顾已保存的内容和个人记忆。
- 日记与配置在自己的电脑保存；API Key 使用 Windows 账户加密保护。
- 右上角显示你设置的名字，点击可打开本地设置。密钥可用眼睛按钮显示或隐藏。
- 右下角信封保存一封本地欢迎信。设置好名字和文字模型后收到，不调用模型、不连接客服。
- F11 切换全屏，Esc 退出。内容区保持 16:9，窗口比例不同时外侧留边。

## 数据与更新

数据位于 `%APPDATA%\LiChatDiary`。调用 AI 功能时，所需聊天、截图、上下文会发送给你配置的模型服务商；联网检索会发送检索词。应用不提供开发者云同步。

退出应用后复制整个数据目录可作完整备份。日记正文和导出档案没有额外加密，密钥配置绑定原 Windows 账户。更新时关闭程序，再运行新安装包，继续使用原数据目录。
